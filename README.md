# Hala Bira Stays

A MERN stack accommodation planning and reservation simulation app for **Dinagyang Festival** in Iloilo City, Philippines.

## Tech Stack
- **MongoDB & Mongoose** — Accommodations catalog and sample stay reservations
- **Express & Node.js** — REST API (`/api/stays`, `/api/reservations`)
- **React & Vite** — Interactive filterable catalog, shortlist persistence, route/closure guide, and booking modal
